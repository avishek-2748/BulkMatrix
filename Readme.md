AI-powered freight forecasting and vessel chartering platform for India’s East Coast bulk importers. Predicts 15/30/90-day freight rates, recommends the right vessel class (Handysize–Capesize) while enforcing port constraints (draft/LOA/beam), and generates Buy/Hold signals for short/medium-term charters. Includes congestion-aware scheduling, weather/cyclone risk alerts, and voyage cost estimation (fuel + FX). Built for SIH 2026.
